# @inkdropapp/math

A React component that renders LaTeX with [KaTeX](https://katex.org/), plus the stylesheet
it needs — KaTeX's own CSS, scoped so it cannot leak into the rest of your page.

Extracted from the [Inkdrop Math plugin](https://github.com/inkdropapp/inkdrop-math) so the
plugin and the website demo share one implementation instead of each carrying a port of it.

The guiding principle: **this package is host-agnostic.** It imports no Inkdrop API.
Everything host-specific arrives as a prop, so the same component works inside the desktop
app, a Waku/Next.js page, or a mobile WebView.

## Install

```shell
npm install @inkdropapp/math katex
```

`react` and `katex` are **peer dependencies** — the host installs and dedupes them. `katex`
in particular is a peer because the stylesheet below is generated from a specific KaTeX
version's CSS; a second, different copy of KaTeX would emit markup the sheet does not match.

## Required stylesheet

```ts
import '@inkdropapp/math/styles.css'
```

Without it KaTeX's markup renders as unstyled fallback text — no runtime warning. The sheet
carries its own WOFF2 fonts in `styles/fonts/`, referenced relatively, so any bundler that
handles `url()` in CSS will emit them.

## Usage

```tsx
import '@inkdropapp/math/styles.css'
import { MathEquation } from '@inkdropapp/math'

export function Equation() {
  return <MathEquation code="\int_0^\infty \frac{x^3}{e^x-1}\,dx = \frac{\pi^4}{15}" />
}
```

As a Markdown code component, with the host's own error styling:

```tsx
import { MathEquation } from '@inkdropapp/math'
import type { CodeComponentProps } from '@inkdropapp/markdown'

export default function Math({ className, children }: CodeComponentProps) {
  return (
    <MathEquation
      code={children[0]}
      inline={(className || '').includes('inline')}
      renderError={error => <span className="my-error">{error.message}</span>}
    />
  )
}
```

### Props

| Prop          | Default | Description                                                                                     |
| ------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `code`        | —       | The LaTeX source.                                                                               |
| `inline`      | `false` | Render inline in a `<span>` rather than in display mode in a `<div>`.                           |
| `className`   | —       | Appended to the `inkdrop-math` scope class on the wrapper.                                      |
| `options`     | —       | Passed to `katex.renderToString`. Pass a stable reference — a fresh literal forces a re-render. |
| `renderError` | —       | Replaces the equation when KaTeX rejects the source. Defaults to `.inkdrop-math-error` text.    |

Rendering happens **during render**, not in an effect, so equations survive server-side
rendering and there is no empty first paint.

`MATH_SCOPE_CLASS` (`'inkdrop-math'`) is exported too, for hosts that need to target the
wrapper from their own CSS.

## Equation numbers

`\begin{equation}` numbering counts with a CSS counter that the sheet resets on
`.mde-preview` — the class `@inkdropapp/uikit`'s `UIMDEPreview` puts on a rendered note. In
a host that does not use that class, numbering runs continuously across the document
instead of restarting per note.

## Regenerating the stylesheet

`styles/` is generated by `scripts/build-styles.mjs` from whichever `katex` this package has
installed. The transform is exported at `@inkdropapp/math/katex-css` so hosts that need
different font URLs can produce their own sheet from the same rules:

```js
import { buildMathStylesheet } from '@inkdropapp/math/katex-css'

const css = buildMathStylesheet(katexCss, { fontUrlPrefix: 'https://cdn.example.com/katex' })
```

The Inkdrop plugin uses this — it injects its stylesheet as text, where a relative `url()`
would resolve against the document rather than the sheet, so it needs an absolute
`inkdrop://` prefix.
